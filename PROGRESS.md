# Progress

What's done, what's broken, what's next. Newest entry first. Each session adds a row before it
ends, saying what changed, what the game test counted, what the proof run was (the feature off,
which checks fail, code put back), what was learned, and what was deliberately not done.

## Where things stand

- **Done:** the Hearth ("Light a hearth. Home is safe."): inside a Hearth Lantern's reach (64 blocks in new worlds) no monster or phantom spawns, blasts, fire and endermen leave blocks alone, animals and pets are safe, items last longer, no fall damage and glass, ice and bookshelves drop themselves; and home comes alive: candles light at dusk and go out in the morning, pets settle by the hearth at night, a garden grows. Six lantern styles, a named home, the "Home" sign; keep your hotbar on death; cheap wood in the stonecutter, re-dyeing and builder trades; an advancements tab. Fabric and NeoForge jars plus the plain data pack, every change released (versions: the GitHub releases). CI builds all of it and runs the load tests, the game tests and the NeoForge game test on every push. The live branch is `public`, pushed to the remote `public` as `main`; `main` is old local history and is never pushed.
- **Broken:** nothing known.
- **Next:** a Short with Gabby's voiceover about home coming alive. Ideas kept for later, each to pass the feel (slow-paced, peaceful, cute): a visitor at your door, a warm home in snowy biomes, a soft good morning. New features need Gabby's pick before they're built.
- **Version lines (Gabby, 2026-10-19):** 26.3 (`public`) and 1.21.1 get updates. **1.20.1 was dropped**: its releases, tags and branch were removed before the mod was listed anywhere. Why: none of the supported wood and decoration mods stops at 1.20.1 (all reach 1.21.1, most 26.3), 1.20.1 is the costliest line to keep (Forge, Java 17, its own harness), and its GitHub downloads were all our own checks.
